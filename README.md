### Employee Management System

Developed a responsive **Employee Management System** using **HTML, CSS, and JavaScript** to efficiently manage employee information through a simple and user-friendly dashboard.

The system allows users to **add, edit, delete, search, filter, and sort employee records**. It also provides real-time dashboard statistics such as total employees, total salary, average salary, and active employees. Employee data is stored using **Browser LocalStorage**, allowing records to persist even after refreshing the page.

**Key Features:**

* Add and manage employee details
* Edit and delete employee records
* Search employees by name, email, or job role
* Filter by department and employment status
* Sort employees by name and salary
* Calculate total and average salary
* Track active employees
* Responsive design for desktop and mobile
* Persistent data storage using LocalStorage

**Technologies:** 
HTML5
CSS3
JavaScript
DOM Manipulation
LocalStorage
